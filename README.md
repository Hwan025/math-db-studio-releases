# Math DB Studio 0.7.1

수학 HWP·HWPX 문서를 PDF 원문과 대조하고 수식·문장 교정을 검토하는 Windows 앱입니다.

**[최신 정식 버전 다운로드](https://github.com/Hwan025/math-db-studio-releases/releases/latest)**

## 실행

Windows x64와 한글 2022가 필요합니다. ZIP 전체를 새 폴더에 풀고 `MathDBStudio.exe`를 실행하세요. EXE와 resources·locales·DLL 등 폴더 전체를 함께 보관합니다. Python·Node·AI 구독은 별도로 준비하지 않습니다. 기존 버전과 작업 자료는 유지하세요.

## 사용 흐름

1. 처음 쓰는 PC는 **한글 연결 설정**을 확인합니다. 첫 화면에 HWP·HWPX를 끌어 놓거나 **문서 가져오기**를 누릅니다. 문서 한 개와 PDF 한 개를 함께 놓을 수 있습니다.
2. PDF 원문과 수식 전·후 코드를 대조하고 수정안을 선택·제외·보류합니다. 초안·메모·결정은 저장되며, 문서를 열거나 이동하는 것만으로 한글을 수정하지 않습니다.
3. **검토 마무리**에서 선택·미결정·보류·기존 반영을 확인한 뒤 **선택 항목 한글에 반영**을 누릅니다. 부분 실패와 남은 항목은 결과에서 확인합니다.
4. 수식·전체 교정본과 마감 결과를 HWPX 또는 HWP로 저장합니다. 출력 사본 저장과 연결된 한글에 새 수정안을 반영하는 동작은 별도입니다.

한글에서 새로 선택한 수식은 가려진 목록에서도 표시하고, 앱 자체 이동은 필터를 유지합니다. 선택을 확인하지 못하면 기존 표시 행과 초안을 유지합니다. 실제 벡터 간격 변경만 확인 대상으로 삼으며 기존 자동 수정안은 **이 수식 규칙 다시 확인**으로 한 행씩 갱신할 수 있습니다.

## 저장과 다시 연결

작업 저장·내보내기·이어하기와 문서 닫기·다시 열기를 제공합니다. 내보낸 JSON이 참조하는 문서·PDF·마감 자료도 보관하세요. JSON 하나에 모든 자료가 들어 있지는 않습니다.

한글 연결 끊김이 확인되면 로컬 검토 저장 후 닫기·종료를 허용하고 **한글 파일 저장 미확인** 안내를 유지합니다. **다시 연결**은 직접 누를 때 마지막 저장·확인된 사본을 사용하며 검토 위치·필터·결정·초안을 유지합니다. 자동 재연결·전체 재분석은 하지 않습니다. 한글에서 저장하지 않은 편집의 복구는 확인할 수 없습니다.

## 확인 범위

dev.15의 기능을 기준으로 정식화했습니다. 모의 검사와 배포 파일 검증을 수행했으며, 실제 한글을 자동 실행하는 검사는 수행하지 않았습니다. HWP 변환·선택·편집창·연결 끊김·복구는 PC와 문서에 따라 확인이 필요합니다. 복잡한 표·그림·배치와 의미 판단은 사용자 검토가 필요합니다.
