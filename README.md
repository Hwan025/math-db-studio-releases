# 수학 DB Studio 0.7.0

[최신 정식 다운로드](https://github.com/Hwan025/math-db-studio-releases/releases/latest) · [전체 버전 및 베타](https://github.com/Hwan025/math-db-studio-releases/releases)

주요 기능·중요 오류 수정은 정식/Latest, 새 수식 규칙 시험 버전은 Pre-release로 배포합니다.

Windows x64용 한글 수식·문서 검토 앱입니다. 한글 연동에는 설치된 한글 2022가 필요합니다. Python·Node·AI 구독을 별도로 설치하거나 준비하지 않습니다.

## 실행

MathDBStudio-0.7.0.zip 전체를 새 폴더에 풀고 MathDBStudio/MathDBStudio.exe를 실행하세요. resources·locales와 모든 DLL/리소스를 함께 보관해야 합니다. EXE만 복사하지 마세요. GitHub의 자동 생성 Source code ZIP은 설치 파일이 아닙니다.

## 주요 기능

- 복잡한 수식은 한글 수식 코드 전·후로 비교하고 후 코드를 편집합니다.
- 탐색창·PDF·수식 목록을 접어 편집 공간을 넓힙니다. PDF 확대는 아래 가로 스크롤바로 좌우 끝까지 이동합니다.
- 문제 전체→해설 전체 순서와 문제·해설 번갈아 보기를 선택합니다.
- PDF OCR·문항 영역 연결, 초안·메모·검토 기록, 문항별 줄바꿈·탭·자간 마감을 제공합니다.

## 저장과 이어하기

이전 프로그램에서 작업을 저장한 뒤 새 앱의 기존 작업 이어하기로 가져오세요. 처음 가져올 때 JSON이 참조하는 문서·PDF·마감 폴더에도 접근할 수 있어야 합니다. 작업 저장과 한글 반영·교정본/마감본 저장은 별개입니다.

첫 실행의 한글 연결 설정에서 환경을 확인하고 공식 모듈을 설정하세요. 한글에서 편집한 연결 작업 사본은 저장 후 변경 가져오기에서 비교·동기화합니다. alpha 버전의 로컬 기록 저장 위치는 유지합니다.

## 지원 범위

미주 연결 문제/해설 및 과목 제목·연속 번호 문단을 지원합니다. 마감 엔진은 미주 연결 문서 중심이며 정밀 표·그림·배치는 한글에서 확인합니다. 새 문서 유형은 후속 업데이트로 추가합니다. 별도 미저장 한글 창과 다른 이름으로 저장한 문서의 자동 추적은 지원하지 않습니다.

기존 배포본이 다른 PC에서도 잘 작동했다는 확인은 사용자보고입니다. 모든 PC·문서 유형·전페이지 수학 내용의 검증 완료를 뜻하지 않습니다.
