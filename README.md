# 수학 DB Studio

Windows용 한글 수식 교정 도구의 공개 배포 저장소입니다.

## 다운로드

- [최신 정식 버전](https://github.com/Hwan025/math-db-studio-releases/releases/latest)
- [전체 버전 및 베타](https://github.com/Hwan025/math-db-studio-releases/releases)

`MathDBStudio-버전.zip`을 받아 전체 압축을 해제한 뒤 `MathDBStudio.exe`를 실행하세요. `_internal` 폴더를 함께 보관해야 합니다. GitHub의 자동 생성 Source code ZIP은 프로그램 설치 파일이 아닙니다.

## 배포 구분

- **정식 / Latest**: 주요 기능 및 중요한 오류 수정의 검증된 배포.
- **베타 / Pre-release**: 새 수식 규칙을 시험하는 배포. 예: `v0.6.32-beta.1`.

## 사용 환경

Windows 10/11 x64. 한글 수식 갱신과 최종 저장에는 설치형 한글이 필요합니다.
기존 검토는 이전 프로그램에서 **작업 저장** 후 새 버전의 **작업 불러오기**로 이어서 사용하세요.

이 저장소는 실행 파일과 사용 안내만 제공합니다. 개발 소스와 작업 문서는 별도로 관리합니다.
오류를 제보할 때는 버전과 오류 문구를 알려주세요. 개인정보가 있는 문서·로그는 공개 이슈에 올리지 마세요.
